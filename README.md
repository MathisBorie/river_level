# river_level

L'objectif de ce projet va être de pouvoir prédir le niveau d'eau sur les rivères.


Nous allons commencer par étudier le cas de la bonne, la rivière principale du valbonnais.

Pour commencer https://hydro.eaufrance.fr met a disposition les niveaux d'eau d'un très grand nombre de rivière, dont la bonne.


les données que nous allons utilisé sont : 

-les niveaux d'eau passée
-les cumulés de neige
-les températures
-les précipitations
